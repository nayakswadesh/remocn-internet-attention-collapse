# Phase 5.5 audio assets

All runtime audio assets are local, project-owned generated files.

- `music.wav`: deterministic procedural electronic score generated by
  `scripts/generate-audio-assets.mjs`.
- `impacts.wav`: deterministic tonal metric impacts generated by the same script.
- `transitions.wav`: deterministic compress, extend, clear, and loop gestures.
- `texture.wav`: deterministic tick and overload texture.
- `voice-placeholder.wav`: timing reference assembled from local Windows SAPI
  segments using Microsoft David Desktop. This is explicitly a placeholder,
  not final commissioned voice talent.

All stems are 48 kHz, stereo, 16-bit PCM and exactly 50 seconds long. No asset
requires a network request or third-party media license.
